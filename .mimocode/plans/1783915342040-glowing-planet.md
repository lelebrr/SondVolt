## FASE 5: Implementacoes Reais - Sensores e Medicoes

### 5.1 Capacitancia real (measurements.cpp)
- Substituir `return (float)duration / 1000.0f` por formula RC real:
  `C = t / (R_known * ln(Vcc / (Vcc - V_threshold)))`
- Usar `PULLUP_RESISTANCE` como R_known
- Calcular ESR simplificado: medir tensao na carga vs descarga
- ESR = (V_charge - V_discharge) / I_peak (aproximacao)

### 5.2 Diodo/LED real (measurements.cpp)
- Ja usa `lastVoltage` - implementar deteccao de tipo:
  - Uf < 0.3V -> Germanio
  - Uf 0.5-0.7V -> Silicio
  - Uf 1.8-3.3V -> LED (cor por tensao)
  - Uf > 3.3V -> Zener ou LED UV
- Medir corrente reversa (aberto = boa isolacao)

### 5.3 Indutancia real (measurements.cpp)
- Metodo de tempo de carga RL:
  - Aplicar tensao conhecida ao indutor
  - Medir tempo para atingir 63.2% (tau = L/R)
  - L = tau * R_serie
- RDC: medir resistencia DC do indutor (metodo de tensao conhecida)

### 5.4 Transistor real (novo: transistor.cpp/h)
- **Deteccao de pinos**: Testar todos os 6 pares de pinos (1-2, 1-3, 2-1, 2-3, 3-1, 3-2)
- **Identificacao BJT NPN/PNP**:
  - Medir queda Vbe (base-emisor): ~0.6V = junction found
  - Identificar Base (pino comuns juncoes em 2 direcoes)
  - Identificar Coletor/Emisor por hFE (hFE CE > hFE CB)
  - Calcular hFE = Ic / Ib usando divisor de tensao conhecido
- **Identificacao MOSFET N/P**:
  - Gate isolado = capacitancia alta entre gate e outros
  - Vgs_th: tensao para comecar a conduzir (~2-4V para N, ~-2 a -4V para P)
- **Leitura hFE real**: Usar circuito com R_base conhecido
  - Ib = (Vcc - Vbe) / R_base
  - Ic medido via tensao no R_coletor
  - hFE = Ic / Ib

### 5.5 IC/CI basico (novo: ic_tester.cpp/h)
- Deteccao basica por juncoes:
  - Testar pares de pinos em ambas as direcoes
  - Mapear juncoes (diodos encontrados)
  - Comparar com padroes conhecidos (74xx, 555, etc)
- Identificacao por pinagem:
  - Pino 1 = GND, Pino ultimo = VCC (padrao comum)
  - Testar com VCC/GND e medir comportamento

### 5.6 Scanner de componentes (measurements.cpp)
- Varredura automatica: testar todos os pares de terminais
- Para cada par: medir R, C (se detectado), diodo (se detectado)
- Classificar automaticamente: resistor, capacitor, diodo, curto, aberto
- Usar logica de decisao arvore:
  - R < 1 ohm -> curto
  - R > 1M ohm -> aberto
  - R 1-1M -> resistor (ler valor)
  - C > 1pF -> capacitor (ler valor)
  - Vf 0.3-3.3V -> diodo/LED
  - 3 terminais com juncoes -> transistor
